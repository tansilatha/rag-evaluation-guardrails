# Historical evaluation reports

Raw historical reports and their underlying datasets are not included in this
public branch. The repository-level
[`final_rag_evaluation_report.md`](../final_rag_evaluation_report.md) is a
sanitized aggregate summary of the existing results. It is not a new
evaluation, and it does not include raw per-case outputs. Review source-data
permissions and model/provider terms before publishing additional reports.
